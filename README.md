# مصرف انرژی هوش مصنوعی و محاسبات سبز

ارائهٔ فارسی با React و Reveal.js؛ مسیر کامل ۳۰ اسلاید، مسیر کوتاه ۲۰ اسلاید.
ارائه‌دهندگان: محمدمهدی صفری و محمدمعین لطیفی.

## اجرای نسخهٔ آماده

ZIP را استخراج کن و با Node.js نسخهٔ 22.13 یا بالاتر از داخل پوشهٔ پروژه اجرا کن:

```sh
npm start
```

آدرس: http://localhost:5173 . پوشهٔ `dist` آماده است و برای اجرای آن نیازی به `npm ci` یا اینترنت نیست.

برای شبکهٔ محلی: `npm start -- --host 0.0.0.0`. برای پورت دیگر: `npm start -- --port 8080`.

## ویرایش و ساخت دوباره

```sh
npm ci
npm run dev
```

پس از تغییر سورس، با `npm run build` خروجی را دوباره بساز. برای میزبانی ایستا، محتویات `dist` را در ریشهٔ سایت قرار بده.

## کنترل‌ها

- فلش چپ و راست: اسلاید بعدی و قبلی
- **G**: نمای کلی؛ **N**: پنل یادداشت؛ **S**: نمای سخنران (پنجرهٔ جدا)
- مسیر کوتاه: http://localhost:5173/?route=quick
- نسخهٔ چاپ: http://localhost:5173/?print-pdf

متن و زمان‌بندی در `src/deck.json` و `src/expansion.ts` قرار دارند. فونت‌ها، تصاویر و قالب‌های میم داخل بسته‌اند. پیوند منابع و اعتبار تصویرها در خود ارائه است.

پنج قالب تکمیلی مستقیماً کنار محتوای اسلایدهای مرتبط دیده می‌شوند. اسلاید آخر لینک و QR مخزن گیت‌هاب را دارد. قالب‌ها از مجموعهٔ Memegen و نسخهٔ بایگانی‌شدهٔ قالب Imgflip در مخزن 0xshubhs/scraper تهیه شده‌اند. تصاویر در `public/images/memes` همراه پروژه‌اند.
